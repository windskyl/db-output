db-output 本地工作台

本地规则采集工作台

在同一个页面里输入需求、导入本地任务文档、校验并运行任务，然后查看结构化结果和易懂摘要。

安全边界

网页只接受 .json、.md、.txt 文本文档，上传大小限制为 300KB，会拒绝二进制内容，也不会执行任何上传文件中的代码。
